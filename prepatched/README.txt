MANUAL INSTALLATION INSTRUCTIONS:
================================

If you do not want to run the installer script:
1. Navigate to your Starmancer game folder:
   <SteamLibrary>\steamapps\common\Starmancer\Starmancer_Data\Managed\
2. Rename the existing 'StarmancerMod.dll' to 'StarmancerMod.dll.orig' as a backup.
3. Copy the 'StarmancerMod.dll' from this folder into 'Starmancer_Data\Managed\'.
4. Launch the game!
